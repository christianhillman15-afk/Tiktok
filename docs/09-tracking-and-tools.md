# Tracking & Tools

> **The point of this doc:** run the whole TikTok → DM → call → close → ascend machine on a **lean, mostly-free stack**, and track the **five numbers that actually predict revenue** — so you always know which videos book calls and which clients ascend to the retainer. If you can't attribute a booked call back to a video, you're optimizing blind.

You do **not** need enterprise software. A solo/small agency can run this entire system on the tools below, most of them free or under ~$50/mo.

---

## The lean tool stack

| Job | Recommended (start free/cheap) | Notes |
|---|---|---|
| **Booking / calendar** | **Calendly** (free tier) or Cal.com (open-source) | Point your bio link **straight at the booking page**, never your homepage. Add reminders + a "how did you find me?" field. |
| **DM automation** | **ManyChat** (free up to ~1k contacts) | Keyword auto-DM (e.g., `AUDIT`). Business account only, DM setting = *Everyone*. **No clickable links in DMs** — capture email, deliver by email. |
| **Link hub / landing** | **Beacons, Stan, or Bitly** (free) — or a one-page landing site | One clean destination: booking + free-audit offer. |
| **Email (deliver freebie + nurture)** | **Brevo** or **MailerLite** (generous free tiers) | Deliver the teardown/booking link by email (DMs can't hold links) and nurture "not now" leads. |
| **Lead/pipeline tracking** | **A Google Sheet** (schema below) → **GoHighLevel / HubSpot free CRM** when volume grows | Start with the sheet. Graduate to a CRM once you're past ~20 active leads. |
| **Website audit (lead magnet)** | **MyWebAudit** or **Insites**, or a manual **Loom** teardown | Auto-generates the report; cuts call prep by 30–60 min. |
| **Editing / captions** | **CapCut** (free) | Burned-in captions add ~12% retention *and* feed TikTok SEO. |
| **Screen recording (teardowns)** | **Loom** (free) or CapCut screen record | Core format for teardowns and audits. |
| **Website build platform** | **WordPress + Elementor**, **Webflow**, or **Duda** | Pick ONE and template it so you can honestly promise a **7-day launch** and protect margin. Duda/Webflow are strong for WaaS (client billing, multi-site). |
| **Client lead-response (deliver on Growth+)** | GoHighLevel or a Twilio-based text-back | The **60-second instant text-back** is what makes a client's site visibly *work* and reduces churn. |
| **Payments / WaaS billing** | **Stripe** (subscriptions) | $0-down monthly plans; keep domain/hosting portable so "you own it" is true. |

> Keep it minimal. The biggest failure mode is buying tools instead of posting videos. This week you only truly need: **Calendly + ManyChat + a link hub + CapCut.**

## The lead-tracking sheet (copy this schema)

One row per lead, from the moment they comment/DM to the moment they close and (later) ascend. This is your entire pipeline until volume forces a CRM.

| Column | Example | Why it's here |
|---|---|---|
| Date first contact | 2026-07-08 | Cohort/velocity tracking |
| Name / handle | @joesplumbing | Who |
| Business + niche | Joe's Plumbing (plumber) | ICP fit check |
| Client city / state | Columbus, OH | Every lead is local to *somewhere* — capture it (you serve nationwide, they serve one town) |
| **Source video** | "3 things killing this plumber's site" | **The attribution link — which content books calls** |
| Entry point | Comment `AUDIT` / DM / bio link | Which CTA worked |
| Stage | DM → Call booked → Called → Proposal → **Won**/Lost/Nurture | Pipeline position |
| Audit sent? | Y (2026-07-08) | Lead-magnet delivered |
| Call date | 2026-07-11 | Booked/held |
| Tier quoted | Growth $299/mo | Deal size |
| **Won / Lost / value** | Won — $299/mo | Revenue |
| **Retainer? (month 3)** | Pending / Yes $1,500/mo | **Ascension tracking (the profit center)** |
| Next action + date | Follow-up recap 7/12 | Nothing falls through |
| Notes | Word-of-mouth only today, embarrassed by mobile site | Context for the call |

**Attribution is non-negotiable:** put **UTM tags** on the bio/booking link and add a **"How did you find me?"** field on the Calendly form. TikTok-sourced bookings are otherwise nearly impossible to attribute — and if you don't know which videos drive calls, you can't make more of them.

## The funnel metrics that matter (and rough benchmarks)

Track these weekly. These map directly to the KPIs in the strategy spine — **leads, not views.**

| Metric | What it tells you | Rough benchmark / target |
|---|---|---|
| **Posting cadence adherence** | Are you feeding the machine? | **4/week sustained** for 90 days |
| **Completion rate** | Hook + length quality | **~70%** for a second push |
| **Saves + shares per video** | High-intent signal ("hire later") | Trend up; these matter more than likes |
| **Keyword comments / DMs per week** (`AUDIT`/`WEBSITE`) | Top-of-funnel intent — **the primary lead signal** | Track weekly trend; this is your #1 leading indicator |
| **DM → call-booked rate** | DM script + offer strength | Aim ~20–40% of qualified DMs book |
| **Personalized DM response rate** | Are your DMs value-first? | ~32% (personalized) vs ~18% (generic) |
| **Call held rate** | Reminder/no-show system | 60–80% held; run no-show recovery |
| **Call → close rate** | Offer + guarantee + diagnosis | Aim ~25–40% on qualified calls |
| **Wedge-to-retainer ascension** | The profit center | **% of website clients on a retainer by month 3** |
| **MRR** | The actual business | WaaS subs + marketing retainers |

**North-star reminder:** a video with **900 views that produced 3 discovery calls beats one with 90k views and zero.** Never optimize on view count or follower count.

## The review rituals

### Weekly review (30 min, e.g., Friday)
1. **Did I post 4x?** If not, batch-film to catch up.
2. **This week's leading indicator:** keyword comments + DMs. Up or down vs last week?
3. **Which video drove the most saves/shares/DMs?** → make 3–5 follow-ups on that topic next week.
4. **Any flops?** Check completion rate. Re-cut the hook, don't delete.
5. **Pipeline hygiene:** update every lead's stage + next action. Nobody sits without a next touch.
6. **Answer the best buyer-question comment with a Video Reply** = a scheduled post.

### Monthly review (60 min)
1. **Attribution roll-up:** which 3 videos/topics booked the most calls? Double down.
2. **Funnel conversion rates:** DM→call, call→close. Where's the biggest drop? Fix that one stage.
3. **Revenue:** new wedge clients closed, MRR added, and **wedge-to-retainer ascension rate.**
4. **Ascension check:** which month-2/3 clients are ready for the Growth Partner pitch? Book those conversations.
5. **Churn check:** any WaaS clients at risk? Ship a win (a fresh edit, a monthly report, a GBP tweak).
6. **Rebalance the content mix** (see `02-content-pillars-and-formats.md`): keep ~70–80% educational/entertaining, ~20–30% offer-forward.

## First-week setup checklist

- [ ] Switch to (or decide on) a **Business account** if conversion — not reach — is your bottleneck
- [ ] **Calendly** booking page live; bio link points **straight to it** (+ UTM + "how did you find me?" field)
- [ ] **ManyChat** keyword automation on one word (`AUDIT`): capture email → confirm → ask one pain question
- [ ] **Email tool** connected to deliver the teardown + booking link
- [ ] **Lead-tracking sheet** created from the schema above
- [ ] **Bio rewritten** to the formula: *what you do + who for + proof + specific CTA*
- [ ] **3 videos pinned:** a result/case study, a free-audit teardown, a "how to work with me" explainer
- [ ] **CapCut** set up for burned-in captions
- [ ] **One build platform** chosen and templated for the 7-day launch
